# Denominator Selection

Choose a denominator that matches the analytical question and state it explicitly before interpreting the result.

1. Define the target population and time window.
2. Apply explicit eligibility and exclusion rules.
3. Identify records with valid data for the measure and classification rule.
4. Separate missing or invalid observations from valid normal observations.
5. Report the resulting denominator and exclusions alongside the estimate.

When comparing groups or times, check whether denominator definitions and missingness patterns are comparable. A change in composition can create an apparent change in prevalence without representing change among the same people.
