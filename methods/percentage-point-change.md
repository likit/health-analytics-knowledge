# Percentage-Point Change

Percentage-point change is the later percentage minus the earlier percentage.

```text
37.2% → 36.8%
36.8% - 37.2% = -0.4 percentage points
```

The prevalence therefore **decreased by 0.4 percentage points**.

This differs from relative percentage change:

```text
(36.8 - 37.2) / 37.2 × 100 ≈ -1.1%
```

Label the quantity explicitly. Do not call a 0.4-percentage-point decrease a “0.4% decrease,” because that wording can be mistaken for relative change. Rounding can affect displayed differences, so calculate from the most precise available values and disclose relevant rounding.
